# Titanic-Data-Science-Project
End-to-end Titanic Data Science and Machine Learning project

An end-to-end Data Science project that analyzes Titanic passenger data, explores survival patterns, performs data cleaning and feature engineering, and builds Machine Learning models to predict passenger survival.

## Technologies Used
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Streamlit
- Plotly

## Project Features
- Exploratory Data Analysis (EDA)
- Missing value treatment
- Outlier investigation
- Feature engineering
- Logistic Regression
- Decision Tree
- Random Forest
- Model evaluation
- Interactive Streamlit dashboard

## Model Performance

| Model | Accuracy |
|---|---:|
| Logistic Regression | 81.56% |
| Decision Tree | 75.98% |
| Random Forest | 79.89% |

## Dashboard
Interactive dashboard for exploring passenger demographics and survival statistics.

## How to Run

1. Clone this repository.
2. Install dependencies:

   `pip install -r requirements.txt`

3. Run the dashboard:

   `python -m streamlit run dashboard/app.py`
